# NBMS Documents

This directory contains public-facing documents for the NBMS draft.

- [NBMS_USAGE.md](NBMS_USAGE.md): how to read and handle NBMS projects.
- [NBMS_SPEC.md](NBMS_SPEC.md): current format specification draft.
- [NBMS_UNRESOLVED_SPEC.md](NBMS_UNRESOLVED_SPEC.md): topics that still need review, decisions, or implementation.
- [NBMS_MONOGAME_VIEWER_ARGUMENTS.md](NBMS_MONOGAME_VIEWER_ARGUMENTS.md): MonoGame Viewer command-line arguments.
- [NBMS_MONOGAME_VIEWER_AUDIO_OPTIONS.md](NBMS_MONOGAME_VIEWER_AUDIO_OPTIONS.md): MonoGame Viewer audio tuning options.

For editor/viewer implementation documents, see [../NBMS.Studio/docs](../NBMS.Studio/docs).
Working notes and review supplements are under [../exsamples](../exsamples).
