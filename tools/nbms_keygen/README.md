# nbms_keygen

Generate an NBMS Phase 4 author keypair.

```text
python tools/nbms_keygen/nbms_keygen.py author-key-2026 keys/
```

Output:

- `keys/author-key-2026.private.json`
- `keys/author-key-2026.public.json`

The private key file contains the Ed25519 seed and must be protected by the author.

# nbms_keygen 日本語版
